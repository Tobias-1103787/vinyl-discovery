# Beschrijving:
In de applicatie kan je vinyl's bekijken, toevoegen en aan jouw 'favorite'-lijst toevoegen.
Hierin kan je de artiest, het label en nog veel meer bekijken.

# User stories:
Gebruiker:
- Ik (de gebruiker) wil (informatie over) mijn favoriete vinyl kunnen bekijken en deze aan mijn lijst toe kunnen voegen zodat ik mijn favoriete artiest kan supporten
- Ik (de gebruiker) wil vinyls die (nog) niet op de site staan toevoegen, zodat ik mijn favoriete vinyl kan delen met anderen
- Ik (de gebruiker) wil met de zoekfunctie kunnen filteren op vinyls van een specifiek genre etc, zodat ik nieuwe vinyls kan vinden

Admin:
- Ik (de admin) wil alle gepubliceerde vinyls kunnen beheren, zodat ik informatie kan toevoegen of kan verwijderen
- Ik (de admin) wil de gebruikers (en hun rechten) beheren zodat ik misbruik kan voorkomen

# MoSCoW:
- Must have:
  - Inloggen
  - Invoervalidatie
  - Verschillende rollen (met verschillende rechten)
  - Zoekfunctie + filters
  - Beveiliging (OWASP top 10)
  - Schakelen van status
  - Diepere validatie
- Should have:
  - Registeren
  - Aanmaken/bewerken van nieuwe vinyl-entries
  - Koppelen van genres, artiesten en labels aan vinyls
- Could have:
  - Aanmaken van nieuwe genre, artiest of label
  - Favoriete vinyls toewijzen
  - Aparte pagina's voor artiesten/labels
- Won't have:
  - vinyl-verkoop
  - prijs, staat etc. weergave
